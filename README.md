# StudyHub — منصة المحاضرات

نسخة أولية قابلة للتشغيل مبنية بـ React + Vite، بواجهة عربية RTL وDark Mode.

## التشغيل
1. ثبّت Node.js إصدار LTS.
2. افتح المجلد في VS Code.
3. افتح Terminal داخل المجلد ونفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. افتح الرابط الذي يظهر في Terminal.

## تفعيل Supabase
1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase/schema.sql`.
3. انسخ `.env.example` إلى ملف اسمه `.env.local`.
4. ضع Project URL وPublishable/anon key في الملف.
5. أعد تشغيل `npm run dev`.

مهم: لا تضع `service_role` key أو أي مفتاح سري في الواجهة الأمامية.

## الوضع الحالي
- عند عدم ضبط Supabase: الواجهة تعمل ببيانات أولية محفوظة محليًا في المتصفح للمعاينة.
- عند ضبط Supabase: تظهر شاشة تسجيل الدخول، لكن مزامنة المنصات والمحاضرات مع جداول قاعدة البيانات ما زالت خطوة تطوير لاحقة.
- تتبع المشاهدة تلقائيًا يعتمد على دعم المنصة الأصلية لتكامل رسمي؛ لا نخزن كلمات مرور منصات المدرسين.
- بيانات البطاقات الأولية أمثلة قابلة للتعديل والحذف وليست بيانات حقيقية.
